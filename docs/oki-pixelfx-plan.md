# PixelFX → Приключения Оки: подготовка v1

Источник: https://github.com/patch-gg/pixelfx
Галерея: https://patch-gg.github.io/pixelfx/
Статус: план интеграции, не подключено к игре. Не менять main без отдельной проверки.

## Набор эффектов для первого прототипа
- weather/rain (проверить точное имя в каталоге): дождь за окном; не перекрывать интерьер.
- weather/fireflies: светлячки в вечерней сцене.
- pickups/coin-spin: анимация монеты в магазине или награде.
- ui/coin-collect: короткая обратная связь при получении монет.
- ui/confetti: редкое событие при достижении.

Точные идентификаторы и пути сверить с docs/CATALOG.md перед импортом.

## Принципы
1. Не заменять спрайт Оки стандартным персонажем библиотеки.
2. Подключать только выбранные эффекты, а не все 244.
3. Учитывать производительность iPhone/iPad: ограничить одновременные частицы, пауза при скрытой вкладке и prefers-reduced-motion.
4. Эффекты не должны менять игровую экономику, скорость ходьбы, клики по предметам или навигацию.
5. Не добавлять новые зависимости без проверки сборки и размера бандла.
6. Сохранить уведомление об авторстве и лицензию MIT в соответствии с исходным репозиторием.

## План внедрения
1. Найти текущий игровой компонент и способ отрисовки.
2. Выбрать интеграцию: JS-модули при совместимом canvas, иначе экспорт sprite sheets.
3. Собрать изолированный демо-экран для мобильного браузера.
4. Проверить запуск/остановку эффектов, касания, FPS и отсутствие ошибок.
5. Только после успешного демо — отдельный PR на внедрение.

## Приёмка
- Оки выглядит и двигается как раньше.
- На мобильном не возникают артефакты вокруг рук и ног.
- Никаких изменений в main и продакшене до одобрения.
