# Oki House movement reference

The browser approach/arrival/action controller adapts the state model and
bounded movement in `woody_auto_move_check`, `woody_update_auto_h_move` and
`woody_auto_move_complete` from dntrnk's unofficial Neighbours-from-Hell-PSP.
The browser implementation is JavaScript with elapsed-time movement, responsive
DOM targets, cancellation and distance-driven Oki animation; it is not a PSP
engine port. No THQ Nordic artwork, audio, level data or game sprites are used.

Source: https://github.com/dntrnk/Neighbours-from-Hell-PSP/blob/main/src/objects/woody.c
