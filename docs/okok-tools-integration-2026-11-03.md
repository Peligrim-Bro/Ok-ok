## Адресные исправления INSPECT v8
1. Тайские госномера: использовать Unicode-aware sanitizeFilename:
```js
function sanitizeFilename(rawName) {
  return (rawName || 'bike')
    .normalize('NFC')
    .replace(/[^\p{L}\p{N}_-]/gu, '_')
    .slice(0, 30) || 'bike';
}
```
2. Не отзывать fallbackBlobUrl на pagehide до открытия PDF: удалить обработчик `window.addEventListener('pagehide', revokeFallbackUrl)`; очищать URL при создании следующего PDF, явном сбросе и при явном закрытии плашки.
3. Защитить от завершения старой обработки после «Очистить»: `let inspectionGeneration = 0`; в начале `capturePhoto` запомнить `const generation = inspectionGeneration`; после каждого await, прежде чем писать в store, проверять `if (generation !== inspectionGeneration) return`; в `clearAllData` после подтверждения вызвать `inspectionGeneration++`.
4. Во время сборки PDF запретить смену режима и очистку либо снимать неизменяемый снимок `mode`/данных для генератора; иначе пользователь может переключить START/RETURN посреди await и получить смешанный акт.
5. В `renderPdfCanvasPage` добавить обработчик `img.onerror`, чтобы битое изображение не подвешивало генерацию.
6. Web Share в Safari после async-сборки PDF может терять user activation. Fallback сохраняет файл, но не гарантирует показ системного меню.
7. Проверить, что отмена Web Share не инициирует скачивание; реальный сбой инициирует ровно одно скачивание.
8. Предупредить, что GPS/время — пользовательская фиксация, не криптографическое доказательство.
