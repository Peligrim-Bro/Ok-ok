# OK-OK Content Pipeline — draft configuration

This directory is isolated from the production site. No deployment or publishing is performed by these files.

## Editorial rules
- Two channels: OK-OK.click tourism/Pattaya and Timur Khan's professional marketing blog.
- Verify every news item with its original dated source. Never invent locations, ratings, safety claims, or testimonials.
- For OK-OK video scripts: mascot Oki must match the approved visual reference; on-screen text must be English only; show exact URL ok-ok.click.
- Preserve existing referral links and partner placements; do not replace or remove them without explicit instruction.
- Publish only after editorial approval; no automatic social posting until channel integrations and permissions are verified.
- No Netlify assumptions. Confirm the current hosting/deployment platform before proposing site changes.

## Workflow
1. niche-research: gather source URLs, publication dates, and factual claims.
2. content-matrix: select tourism and professional-blog pillars.
3. hook-generator: create six fact-grounded opening angles.
4. reels-scripting / post-formatter: create scripts and posts.
5. quality gate: check source citations, mascot consistency, language, URL, and affiliate integrity.
6. approval queue: save drafts, never auto-publish.
7. analytics: measure real reach, click-throughs, leads and conversions only from connected sources.

## Initial content pillars
Tourism: anti-scam; local food and places; transport and travel tools; exchange and practical tips.
Professional: AI-built websites; marketing automation; real case studies; lead generation.
